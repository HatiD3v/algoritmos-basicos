# Variables y manipulacion de datos

## Todo programa

1. Guarda informacion
2. Modifica informacion
3. cuenta informacion
4. transforma informacion

## A) Variables - 'Cajas' que guardan datos

una variable es un espacio en memoria que guarda un dato, como una caja al que se le coloca un nombre y se le almacena un objeto.

Como pensar en una variable? piensa en: que informacion necesito recordar?

### Tipos de datos basicos

1. Numeros enteros sirven para:
   - Edades
   - Cantidades
   - Contadores
2. Numeros decimales sirven para
   - Precios
   - Alturas
   - Temperaturas
3. Texto (strings)
   - Nombres
   - Mensajes
   - Correos
4. Booleanos
   - Validaciones
   - Decisiones

## B) Manipulacion de numeros (cambiar o trabajar con los datos)

| Operación      | Ejemplo |
| -------------- | ------- |
| suma           | 5 + 2   |
| resta          | 5 - 2   |
| multiplicación | 5 * 2   |
| división       | 10 / 2  |
