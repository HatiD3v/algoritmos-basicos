# 🧠 Arrays / Listas

## A) Que es una lista?🤔

Una lista guarda multiples datos en una sola estructura (espacio en memoria contigua que se almacena en la region de memoria llamada heap)
Se piensa en una fila de cajas y cada caja tiene una posicion.
Cada caja o elemento tiene una posicion marcada por indice normalmente inicia de 0 a N como los indices de un libro.

## B) Recorrer listas 🏃🏻‍♂️‍➡️

Es visitar cada elemento uno por uno, a esto se le llama iteracion es el proceso de repetir una accion.

## C) Buscar elementos 🔍

Encontrar un valor en especifico mientras se realiza una iteracion.

## D) Encontrar maximo y minimo 👀

- Numero maximo y minimo
  - encontrar el numero mas grande
  - la idea mental seria: se debe guardar un 'numero mayor y menor actual' y compararlos por cada nuevo numero y reemplazar si aparece un numero mayor o menor

## E) Filtrar datos 🗃️

Quedarse solo con ciertos elementos si cumplen cierta condicion.

## F) Promedios 📊

Un promedio comunmente necesita un acumulador y contador
