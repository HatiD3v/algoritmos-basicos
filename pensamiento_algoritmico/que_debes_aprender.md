# A)Descomposición de problemas

## *Consiste en dividir algo grande en pequeñas tareas para hacerlas más simples*

- Se divide en:
- Entrada
- Proceso
- Salida

## B)Entrada → Proceso → Salida

Todo algoritmo tiene:

- *Entrada*
Que informacion recibe

- *Proceso*
Que se hace con esa informacion

- *Salida*
Que resultado produce

### Ejemplo conceptual

`Entrada → Edad`
`Proceso → comparar si es > 18`
`Salida → 'mayor de edad'`

## C)Pseudocódigo básico

Es escribir logica en español estructurado.

``` Pseudocodigo
INICIO

pedir número
multiplicar número por 2
mostrar resultado

FIN
```

No importa la sintaxis perfecta.
*Importa el orden logico*
