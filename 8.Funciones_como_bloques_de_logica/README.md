# Que es una funcion? 🤔

- Es un bloque de codigo que realiza una funcion en especifico y se puede reutilizar sin estar repitiendo codigo.
- Una funcion recibe datos los procesa y devuelve el resultado.
- Una funcion debe hacer una sola tarea, una sola responsabilida.

## A) Modularizacion 📚

- Significa dividir un problema en pequeñas partes para lograr obtener una solucion.
- Es mas facil de entender
- Mas facil de corregir
- mas reutilizable

## B) Reutilizacion de codigo 🔃

- Es escribir una vez y usar multiples veces

## C) Parametros 🔠

- Son datos que recibe la funcion

## D) Retorno ⏪

- Es devolver un resultado, el resultado que da la funcion.

## E) Como pensar en una funcion correctamente 🧠

- Que hace? > responsabilidad
- Que necesita? > parametros
- Que devuelve? > retorno
